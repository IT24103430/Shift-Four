# Four-drone fleet implementation

## Models

- Scout — compact cyan reconnaissance sensor chassis.
- Flanker — swept aggressive orange/red flank chassis.
- Guard — broad heavy armored red-warning chassis.
- Interceptor — narrow arrowhead high-speed purple chassis.

Each original model is a distinct OBJ mesh with UV coordinates and material labels. The door remains a separate UV-mapped OBJ. The Unity installer assigns the corresponding drone mesh to each gameplay type without modifying AI logic or physics components.

## Unity

1. Open project using the Unity version from `ProjectSettings/ProjectVersion.txt`.
2. Allow scripts and OBJ models to import.
3. For fresh project use **Tools > Shift Four > Generate Greybox Once**.
4. For an existing scene use **Tools > Shift Four > Install Drone + Door Models**.
5. Inspect all four agents and verify collisions, NavMesh, player damage and door interaction.

The scene and prefabs are generated by Unity's editor tooling and are not precompiled or run in this archive.

## Blender source files

The build environment does **not** have Blender installed. Actual `.blend` binaries are therefore NOT included. Generate the five editable `.blend` files using:

```sh
blender --background --python ArtSource/GeneratedModels/create_blend_sources.py
```

Submit UV Editing workspace screenshots and save `.blend` files after reviewing/importing.

## Scope

No AI logic changes. No collider or pathfinding changes. Never use the mesh collider as gameplay collider. Distinct material labels must be verified in the Unity render pipeline.
